# 📑 VSN Master Study Guide: Sales Contracts

🎯 **Goal:** This master document outlines the structure of the VSN Sales Contract Study Set. From here, you can navigate linearly through the entire course.

💡 **KEY POINT:** To view any topic, open the corresponding file name exactly as written. **Do not click; open the file directly in your text editor or viewer.**

*   Open file **01_Initiation_Anbahnung.md**

*   Open file **05_Vocabulary_English.md**
    *   Essential business English vocabulary and key concepts for international trade.
*   Open file **06_Briefe_Schreiben.md**
    *   Detailed German guide and easy-to-memorize templates for business letters.
*   Open file **07_Übungen_Briefe.md**
    *   Practical exercises for writing business letters in German.
*   Open file **08_Lösungen_Briefe.md**
