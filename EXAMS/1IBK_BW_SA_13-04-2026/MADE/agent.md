# VSN Learning Material Generator - Memory

## VSN Brand Guidelines
- **Primary Color**: `#1e2e48` (VSN Dark Blue - Headers, tables)
- **Secondary Color**: `#fbc92d` (VSN Yellow - Accents, borders)
- **Complementary Color**: `#dc4ebf` (VSN Magenta - Nav highlights)
- **Typography Body**: Open Sans
- **Typography Monospace**: Roboto Mono
- **Design Philosophy**: Minimal and UX focused
- **Callout Boxes**:
  - Key Definition: Magenta (`rgba(220, 78, 191, 0.7)`), white text
  - Supplemental Info: Blue (`rgba(41, 128, 185, 0.7)`), white text
  - Practical Tip: Yellow (`rgba(251, 201, 45, 0.7)`), dark text (`#1e2e48`)
- **Visual Elements**:
  - Logo: `assets/VSN_new.png`
  - Graphics: SVG only
- **Print requirements**: `A4`/`Letter`, `@media print` with `.page-break` and PDF optimized.

## Notes
- Generate html files using embedded CSS to produce beautifully styled and print-ready educational materials.
- Callout boxes rely on 70% opacity, drop shadows, and 8px border radiuses.
- Use a 2-column layout when producing bilingual translations (English & German side-by-side).
