## Question 1

### English

Solve for x: **3x + 8 = 29**

### Deutsch

Löse nach x auf: **3x + 8 = 29**

---

### ✅ Answer

**x = 7**

---

### 📝 Step-by-Step Breakdown

1. **Start with:** 3x + 8 = 29

2. **Subtract 8 from both sides** (inverse of +8):
   ```
   3x + 8 - 8 = 29 - 8
   3x = 21
   ```

3. **Divide both sides by 3** (inverse of ×3):
   ```
   3x ÷ 3 = 21 ÷ 3
   x = 7
   ```

4. **Check your answer** by substituting back:
   ```
   3(7) + 8 = 21 + 8 = 29 ✓
   ```

## Question 2

### English

Solve for x: **x/4 - 5 = 3**

### Deutsch

Löse nach x auf: **x/4 - 5 = 3**

---

### ✅ Answer

**x = 32**

---

### 📝 Step-by-Step Breakdown

1. **Start with:** x/4 - 5 = 3

2. **Add 5 to both sides** (inverse of -5):
   ```
   x/4 - 5 + 5 = 3 + 5
   x/4 = 8
   ```

3. **Multiply both sides by 4** (inverse of ÷4):
   ```
   x/4 × 4 = 8 × 4
   x = 32
   ```

4. **Check your answer:**
   ```
   32/4 - 5 = 8 - 5 = 3 ✓
   ```

## Question 3

### English

Solve for x: **2(x - 3) = 14**

### Deutsch

Löse nach x auf: **2(x - 3) = 14**

---

### ✅ Answer

**x = 10**

---

### 📝 Step-by-Step Breakdown

**Method 1: Divide first (often easier)**

1. **Start with:** 2(x - 3) = 14

2. **Divide both sides by 2:**
   ```
   (x - 3) = 14 ÷ 2
   x - 3 = 7
   ```

3. **Add 3 to both sides:**
   ```
   x = 7 + 3
   x = 10
   ```

4. **Check:**
   ```
   2(10 - 3) = 2 × 7 = 14 ✓
   ```

---

**Method 2: Expand first**

1. **Start with:** 2(x - 3) = 14

2. **Expand:** 2x - 6 = 14

3. **Add 6 to both sides:** 2x = 20

4. **Divide by 2:** x = 10

---

> **⚡ EXAM TIP:** Both methods work! Method 1 (divide first) is usually simpler when the coefficient is small. Choose whichever feels more comfortable for each problem.
