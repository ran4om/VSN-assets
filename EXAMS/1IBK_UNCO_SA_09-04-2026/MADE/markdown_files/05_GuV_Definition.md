# Gewinn- und Verlustrechnung | Income Statement (G&V)

> **DEFINITION:** The Income Statement (Gewinn- und Verlustrechnung - G&V) summarizes revenues, costs, and expenses during a period (usually a fiscal year). Its purpose is to determine net profit or loss.

---

## Structure | Struktur

### English

The Income Statement shows the financial performance over a period:
- **Revenues (Erträge)** - income from sales, services, etc.
- **Expenses (Aufwände)** - costs incurred to generate revenue

### Deutsch

Die G&V zeigt die finanzielle Leistung über eine Periode:
- **Erträge** - Einnahmen aus Verkäufen, Dienstleistungen, etc.
- **Aufwände** - Kosten zur Erzielung von Erträgen

---

## T-Account Format | T-Konto Format

```
    ┌─────────────────────────────────────────────┐
    │         GEWINN- UND VERLUSTRECHNUNG          │
    ├──────────────────────┬──────────────────────┤
    │        SOLL          │        HABEN         │
    │    (AUFWÄNDE)        │      (ERTRÄGE)       │
    │                     │                      │
    │  Handelswareneinsatz│  Handelswarenerlöse  │
    │  Personalaufwand   │  Mieterträge         │
    │  Mietaufwand       │  Provisionserträge   │
    │  Zinsaufwand       │  Zinserträge         │
    │  ...               │  ...                 │
    ├──────────────────────┼──────────────────────┤
    │  Summe Aufwände     │  Summe Erträge       │
    └──────────────────────┴──────────────────────┘
         GEWINN = Erträge - Aufwände
```

---

## Profit Calculation | Gewinnermittlung

### English

```
Profit = Revenues - Expenses

If Revenues > Expenses = Profit (Gewinn) ✓
If Expenses > Revenues = Loss (Verlust) ✗
```

### Deutsch

```
Gewinn = Erträge - Aufwände

Wenn Erträge > Aufwände = Gewinn ✓
Wenn Aufwände > Erträge = Verlust ✗
```

---

## 💡 KEY POINT

> **IMPORTANT:** The Income Statement is also called "Erfolgsrechnung" because it shows whether the business was successful (profit) or not (loss) during the period.

---

## ⚡ EXAM TIP

Remember the structure of the G&V:

- **Left side (Soll):** Aufwände (Expenses) - costs of goods, personnel, rent, etc.
- **Right side (Haben):** Erträge (Revenues) - sales revenue, rental income, etc.
- **Result:** If right > left = Gewinn, if left > right = Verlust
