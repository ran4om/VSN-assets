# Die Bilanzgleichung | Balance Sheet Equation

> **DEFINITION:** The Balance Sheet Equation states that total assets must always equal total capital (equity + liabilities).

---

## The Formula | Die Formel

### English

```
Assets = Equity + Liabilities
AKTIVA = EIGENKAPITAL + FREMDKAPITAL
```

### Deutsch

```
Aktiva = Eigenkapital + Fremdkapital
```

---

## Derived Formulas | Abgeleitete Formeln

### English

```
Equity = Assets - Liabilities
Eigenkapital = Aktiva - Fremdkapital
```

### Deutsch

```
Eigenkapital = Aktiva - Fremdkapital
```

---

## Visual Representation | Visuelle Darstellung

```
    ┌─────────────────────────────────────────────┐
    │                 BILANZ                       │
    ├──────────────────────┬──────────────────────┤
    │        SOLL          │        HABEN         │
    │      (AKTIVA)        │      (PASSIVA)       │
    │                     │                      │
    │  Anlagevermögen     │    Eigenkapital      │
    │  Umlaufvermögen     │    Fremdkapital      │
    │                     │                      │
    ├──────────────────────┼──────────────────────┤
    │   Summe Aktiva      │   Summe Passiva      │
    │          =          │          =           │
    └──────────────────────┴──────────────────────┘
         Die Summen müssen immer gleich sein!
```

---

## 💡 KEY POINT

> The balance sheet equation is the foundation of all accounting. Every transaction must keep this equation in balance!

---

## ⚡ EXAM TIP

When calculating Eigenkapital:
- Simply subtract Fremdkapital from Aktiva
- This shows the owner's claim on the company assets
